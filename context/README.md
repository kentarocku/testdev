# context/ — 事実の棚

エージェントが参照する「事実データ」を格納するフォルダです。
ここの充実がエージェント精度向上の核心です。

## フォルダ構成

| フォルダ / ファイル | 内容 |
|---|---|
| `clients/` | 顧客ごとの情報（課題、担当者、契約内容など） |
| `company/` | 自社情報（ミッション、組織、サービス概要など） |
| `members/` | チームメンバーのプロフィールと役割 |
| `owner/` | オーナー（自分）のパーソナリティ・判断基準・優先順位 |
| `partners/` | 協力会社・パートナーの情報 |
| `services/` | 自社サービスの詳細仕様・提供価値 |
| `timeline/` | プロジェクト・案件のタイムライン・進捗 |
| `glossary.md` | このプロジェクト固有の用語定義集 |

## 運用ルール

- 各フォルダ内はエンティティ単位でファイルを作成する（例: `clients/acme-corp.md`）。
- 情報が古くなったら更新する。日付を記載しておくと管理しやすい。
- エージェントへの指示文に「`context/clients/〇〇.md` を参照」と明示すると精度が上がる。
