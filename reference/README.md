# reference/ — 参照辞書

必要なときだけ呼び出す詳細ルール・ガイドラインを格納します。
`CLAUDE.md` には書ききれない詳細をここに切り出します。

## ファイル例

| ファイル名（例） | 内容 |
|---|---|
| `voice-guide.md` | 文体・トーン・言い回しのガイド |
| `tool-usage.md` | ツールの使い分け表・優先順位 |
| `template-sns.md` | SNS投稿テンプレート集 |
| `template-email.md` | メールテンプレート集 |

## 運用ルール

- エージェントへの指示に「`reference/〇〇.md` を参照」と明示して使う。
- 常時読み込ませるものは `CLAUDE.md` に昇格させる。
- 使われなくなったファイルは削除またはアーカイブする。
